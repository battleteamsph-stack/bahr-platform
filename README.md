# 🌟 مستودع إضافات منصة بحر لتطبيق Valenced

مستودع إضافات مجتمعي رسمي لتطبيق **Valenced** على أندرويد، يضم التعريب الكامل لواجهة ديسكورد، الترجمة الفورية للمحادثات، وأدوات الحماية والإدارة.

---

## 🚀 طريقة إضافة المستودع وتثبيت الإضافات في Valenced

1. افتح تطبيق **Valenced**.
2. توجّه إلى: **الإعدادات (Settings)** ⚙️ ⬅️ **الإضافات (Plugins)** 🧩 ⬅️ **متقدم (Advanced)**.
3. في خانة **«رابط المستودع»**، الصق الرابط التالي:
   ```text
   https://raw.githubusercontent.com/battleteamsph-stack/bahr-platform/main/index.json
   ```
4. اضغط على زر **«إضافة مستودع»**.
5. ستظهر لك قائمة الإضافات مباشرة في التطبيق لتثبيتها بنقرة واحدة!

---

## 📦 الإضافات المتوفرة في المستودع

### 1. 🌐 التعريب العربي والترجمة الفورية (`arabic.ui` v1.1.1)
- **تعريب شامل**: ترجمة أكثر من **5004** عبارة في واجهة ديسكورد بالكامل للعربية السليمة.
- **ترجمة المحادثات الفورية**: ترجمة أي رسالة أو محادثة فورياً بنقرة زر داخل الشات.
- **دعم DeepL API**: ترجمة سريعة وعالية الدقة مع التبديل التلقائي بين الخطة المجانية والمدفوعة (`:fx`).

### 2. 🛡️ حارس بحر — كشف المحتوى الممنوع (`bahr.guard` v2.5.3)
- أداة مساعدة للمراجعة البشرية وإدارة الخوادم باستخدام الذكاء الاصطناعي.
- فحص النصوص والصور (Vision) مع اقتباس حرفي ودعم نظام الطبقتين والتوازي الذكي.
- نطاق أمان ضيق ومراجعة بشرية أولاً بدون أي حظر تلقائي.

### 3. 🗑️ حذف رسائلي (`bahr.purge` v1.0.0)
- حذف جميع رسائلك أو عدداً محدداً منها في أي محادثة خاصة أو قروب أو قناة سيرفر بنقرة زر أو بأوامر سريعة.

### 4. ⏰ الإرسال التلقائي (`bahr.autosend` v1.0.0)
- جدولة وإرسال الرسائل تلقائياً إلى أي غرفة أو محادثة مع تحديد الفاصل الزمني والعدد.
