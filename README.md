# 🌊 منصة بحر الدعوية

تطبيق منصة بحر الدعوية - نسخة معدلة بالكامل مع تعريب شامل وترجمة فورية للرسائل لحظة وصولها، وشعار وهوية مخصصة.

---

## 🌟 مميزات المنصة

- 🎨 **هوية مخصصة**: اسم التطبيق في النظام وعلى شاشة البداية هو **منصة بحر الدعوية** مع الشعار الرسمي بالخط العربي المضيء.
- 🌐 **تعريب كامل وشامل**: ترجمة أكثر من 5,000 عبارة في الواجهة والقوائم والإعدادات بدقة عالية.
- ⚡ **ترجمة فورية للمحادثات**: ترجمة رسائل المستخدمين الأجانب في الشات مباشرة لحظة وصولها دون الحاجة لمغادرة الروم أو إعادة تحميل الشاشة.
- 🤖 **دعم محركات متعددة**: إمكانية الترجمة عبر Google Translate مجاناً أو ربط حساب DeepL API لترجمة احترافية.
- 🏷️ **استبدال تلقائي للأسماء**: استبدال كافة التسميات الإنجليزية (`Discord` و `Valenced`) باسم **منصة بحر الدعوية** في جميع القوائم.
- 💾 **حفظ محلي فائق السرعة**: حفظ أي ترجمات جديدة محلياً على الجهاز لتعمل دون استهلاك إضافي للبيانات.

## 📥 تحميل وتثبيت التطبيق

يمكنك تحميل ملفات التثبيت مباشرة من قسم **[Releases](https://github.com/battleteamsph-stack/bahr-platform/releases)**:

### 1. تثبيت التطبيق:
1. قم بتحميل ملف `منصة_بحر_الدعوية.apks` من صفحة Releases.
2. افتح الملف عبر تطبيق **SAI (Split APKs Installer)** أو تطبيق **MT Manager**.
3. اضغط **تثبيت (Install)**.

### 2. تفعيل الإضافة:
1. افتح تطبيق **منصة بحر الدعوية**.
2. اذهب إلى **الإعدادات (Settings)** -> **Plugins (الإضافات)**.
3. اضغط على **تثبيت إضافة (Install Plugin)** واختر ملف `arabic.ui@1.1.0.zip`.
4. قم بتفعيل الإضافة وستتحول الواجهة والمحادثات إلى العربية فوراً!

## 📂 محتويات المستودع

- `index.js`: الكود المصدري الكامل لإضافة التعريب والترجمة الفورية.
- `manifest.json`: ملف تعريف الإضافة لنظام Valenced / Revenge.
- `index.json`: مستودع الإضافات لتلقي التحديثات التلقائية.
- `arabic.ui@1.1.0.zip`: حزمة الإضافة الجاهزة للاستيراد المباشر.
